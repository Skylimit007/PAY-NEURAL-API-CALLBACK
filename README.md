# M-Pesa Daraja STK Push Node.js Fullstack Boilerplate

This repository contains a complete implementation of **Safaricom M-Pesa Daraja API 3.0** implementing an interactive frontend web checkout card and a secure Node.js backend.

## 🛠️ Step-by-Step Installation

1. **Extract the ZIP file** and navigate into the project directory:
   ```bash
   cd mpesa-daraja-complete-project
   ```

2. **Install all native project dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment Variables**:
   Open the `.env` file and replace the following placeholder values with your active Sandbox credentials obtained directly from your [Safaricom Developer Portal App Profile](https://developer.safaricom.co.ke/):
   * `MPESA_CONSUMER_KEY`
   * `MPESA_CONSUMER_SECRET`

## 🛜 Setting Up Webhook Callbacks via Ngrok

Safaricom sends transaction confirmation details asynchronously. Since your localhost environment cannot receive requests directly from the public internet, you must establish an external tunnel using **ngrok**:

1. Download and authenticate ngrok on your system, then start a tunnel on port `3000`:
   ```bash
   ngrok http 3000
   ```

2. Copy the secure **HTTPS URL** generated by ngrok (e.g., `https://a1b2-34-56-78.ngrok-free.app`).

3. Open your `.env` file and append `/api/callback` to your tunnel URL to define your live callback endpoint:
   ```env
   CALLBACK_URL=https://a1b2-34-56-78.ngrok-free.app/api/callback
   ```

## ⚡ Execution

1. Start your local development backend server process:
   ```bash
   npm run dev
   ```

2. Open your preferred browser and load:
   `http://localhost:3000`

3. Enter your personal **Safaricom phone number** and click **Pay Now** to receive your test payment prompt. Watch your active backend console terminal window to observe raw incoming webhook tracking parameters structural payloads immediately after performing PIN input validation actions on your test phone.
